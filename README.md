## ✨ Key Features
- **Modern & Interactive UI:** Features 3D mouse parallax on the hero section and a custom magnetic CTA button.
- **Neural Network Background:** An interactive particle background that reacts to mouse movement across the entire site.
- **Dual Theme Support:** Persistent Light and Dark modes with automatic system preference detection.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens with seamless navigation.
- **Custom Form Validation:** Sleek, custom-designed form feedback for a professional contact experience.
- **SEO Optimized:** Meta tags, semantic HTML5, and accessibility-ready structure to rank on search engines.

## 🛠️ Built With
- **Logic:** Vanilla JavaScript (ES6+)
- **Styling:** Advanced CSS3 (Custom Variables, Flexbox, Grid, Glassmorphism)
- **Structure:** Semantic HTML5
- **Icons:** [UX Wing Icons](https://uxwing.com/)
- **Animation:** Canvas API for interactive particles
